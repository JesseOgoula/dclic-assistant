# 🤖 Walkthrough : Vos nouveaux Skills D-CLIC

Félicitations, vos **5 agents spécialisés** sont maintenant intégrés à votre espace de travail ! Ils ont été programmés pour connaître les bonnes pratiques du *Manuel des Tuteurs OIF D-CLIC*. 

À tout moment, vous pouvez faire appel à moi (ou à l'un de ces sous-agents) pour vous assister.

---

## 🛠️ Comment utiliser ces Skills ?

Pour déclencher un skill, il vous suffit de me le demander en langage naturel dans notre conversation. L'IA saura automatiquement qu'elle doit utiliser le contexte et les instructions du skill concerné. 

Voici quelques exemples de commandes (prompts) que vous pouvez me donner pour chaque skill :

### 1. 💬 Skill : `communication_apprenants`
> *"Rédige-moi une relance pour 3 apprenants (Ali, Fatima et Jean) qui ne se sont pas connectés depuis une semaine."*

> *"Génère le message WhatsApp pour annoncer le début de la Séquence 2, avec la visio prévue mardi à 19h."*

### 2. 📝 Skill : `correction_devoirs`
> *"Voici le devoir M3C de l'apprenant X : [coller le devoir]. Peux-tu l'évaluer selon la grille D-CLIC et me préparer le message de feedback ?"*

### 3. 📊 Skill : `redaction_rapports`
> *"Prépare mon rapport hebdomadaire S4. J'ai eu 40 présents à la visio de mardi. 70% ont validé le devoir M10A. J'ai un souci avec 5 apprenants qui décrochent."*

### 4. ❓ Skill : `support_apprenants_faq`
> *"Un apprenant m'écrit sur WhatsApp qu'il voit la séquence 3 grisée sur Moodle. Formule-lui une réponse pour l'aider."*

### 5. 🎥 Skill : `preparation_visio`
> *"Je dois animer ma visio de Séquence 3 demain. Le thème est la gestion de projet et le diagramme de Gantt. Propose-moi un scénario d'une heure bien interactif."*

---

> [!TIP]
> Si vous souhaitez affiner le comportement de ces agents (ex: ajouter un nouveau type de rapport, changer la signature par défaut), vous pouvez me demander de mettre à jour le fichier `SKILL.md` correspondant dans le dossier `.agents/skills/`.
